プライバシーポリシー

最終更新日: 2026年8月28日

LumenCamは、「一人で撮る」「友達に見てもらいながら撮る」「友達と同時に撮る」という 3つの撮り方と、あえて画質を粗くしたフィルム風の質感を特徴とするカメラアプリです。 本ページでは、これらの機能を提供するために、どのような情報を、どのように取り扱っているかを 具体的にご説明します。

1. LumenCamの機能と、それぞれで扱う情報

① 通常の撮影(一人で撮る)

端末のカメラで撮影した写真は、端末内のみに保存されます。サーバーへの通信は一切発生しません。 撮影した写真は、独自のフィルター処理(解像度を意図的に落とし、粒子感・色被り・ヴィネットを加える処理)を 端末内で行ったうえで保存され、12枚たまるまでは「未現像」の状態としてフィルムのネガのような 見た目でのみ表示されます。

② 友達に見てもらいながら撮る

この機能を使うには、Firebase Authenticationによる匿名認証(氏名・メールアドレス等の入力は不要)で 発行された、端末ごとの識別ID(uid)を用います。招待した友達が画面を見てくれている間だけ シャッターが切れる仕組みで、この「見ている/見ていない」という状態と、招待した相手のuidを、 Cloud Firestore(Googleが提供するデータベース)に一時的に記録します。 撮影が完了すると、その写真はFirebase Storageを通じて相手の端末にも自動的に届けられ、 相手が受け取った時点で、サーバー上のコピーは削除されます。

③ 友達と一緒に撮る

友達を誘い、双方の画面でカウントダウンを同期させたうえで、同時にシャッターが切れる機能です。 招待・カウントダウンの同期には②と同様にCloud Firestoreを、撮影後の写真の受け渡しには Firebase Storageを使用します。招待は1分間有効で、応答がなければ自動的に無効になります。

④ フレンド機能

②・③の機能を通じて一度やり取りが成立した相手、または招待コードを使って追加した相手は、 「フレンド」として、お互いのuidと表示名(ニックネーム)のみがCloud Firestoreに記録されます。 フレンドを解除すると、以後その相手からの招待が届かないよう、ブロック状態としても記録されます。

⑤ アバター機能

端末に保存されている写真を選び、Appleの標準フレームワーク(Vision)を用いて背景を自動的に 取り除いた、簡易的な似顔絵風の画像を作成できます。この処理はすべて端末内で完結し、 サーバーへのアップロードは行いません。

⑥ サブスクリプション・アプリ内課金

「友達に見てもらいながら撮る」「友達と一緒に撮る」機能は、サブスクリプション(月額または年額、 1週間の無料トライアル付き)へのご加入、または「フィルム」(消費型のアプリ内課金)のご購入により 利用可能になります。決済処理はAppleが提供するStoreKitを通じて行われ、開発者はクレジットカード 番号などの決済情報を直接取得しません。購読状態(加入中かどうか)のみを、アプリ内の判定に使用します。

2. 取得する情報の一覧

匿名ユーザーID(uid) Firebase Authenticationの匿名認証により発行。氏名・メールアドレス・電話番号等の入力は求めていません。
表示名(ニックネーム) 友達に表示するための、ユーザーが任意に決める呼び名です。実名の入力は不要です。
写真データ 上記1の②・③の機能を使った場合のみ、相手に届けるために一時的にFirebase Storageへアップロードされます。相手が受け取った時点、または一定期間経過後に自動的に削除されます。
フレンド・招待の記録 フレンドのuid・表示名、招待コードの発行・使用履歴をCloud Firestoreに保存します。
プッシュ通知トークン 招待の通知を届けるため、Firebase Cloud Messagingのトークンを取得・保存します。
購読・購入状態 Appleのシステム(StoreKit)を通じて確認するのみで、決済情報自体は取得しません。

3. 委託先・第三者への提供

LumenCamは、上記の機能を提供するために、以下のGoogle LLC提供のFirebaseサービスを利用しています。

  • Firebase Authentication(匿名認証)
  • Cloud Firestore(フレンド・招待情報のデータベース)
  • Firebase Storage(写真の一時保存)
  • Firebase Cloud Messaging(招待の通知)
  • Firebase Cloud Functions(通知送信処理)

上記以外の第三者(広告配信事業者、アナリティクス事業者を含む)への情報提供は行っていません。 LumenCamには広告表示機能・行動分析(アナリティクス)機能は組み込まれていません。

4. データの保存期間・削除

  • 端末内に保存された写真は、ユーザー自身が削除するまで保持されます。アプリを削除すると、端末内のデータは失われます。
  • 友達との間で共有された写真は、相手が受け取った時点で、サーバー上の一時コピーが削除されます。
  • LumenCamは匿名認証のみを採用しているため、アプリの削除・端末の機種変更を行うと、それまでのフレンド関係やアカウント状態を引き継ぐことができません。この点はあらかじめご了承ください。
  • フレンド・招待情報の削除をご希望の場合は、下記のお問い合わせ先までご連絡ください。

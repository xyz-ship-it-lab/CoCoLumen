プライバシーポリシー

最終更新日: 2026年8月25日

はじめに

CoCoLumen(以下「本アプリ」)は、個人開発者 SUZUNOYA(以下「開発者」)が提供する、 誰かに見てもらいながら撮影する体験を楽しむためのカメラアプリです。 本ポリシーは、本アプリの利用にあたって取得する情報とその取り扱いについて説明するものです。

取得する情報

匿名ユーザーID Firebase Authenticationの匿名認証により、端末ごとに一意のIDを発行します。氏名・メールアドレス・電話番号などの個人を直接特定できる情報は取得しません。
表示名 本アプリ内で友達に表示するための任意のニックネームです。実名の入力は不要です。
写真データ 撮影した写真は、基本的に端末内にのみ保存されます。「友達に見てもらう」「友達と一緒に撮る」機能を使った場合のみ、相手に届けるために一時的にサーバー(Firebase Storage)へアップロードされ、相手が受け取った時点、または一定期間経過後に自動的に削除されます。
フレンド・セッション情報 招待・承諾のやり取りや、フレンドとして記録した相手のID・表示名を、Firestore(データベース)に保存します。
プッシュ通知トークン 招待などの通知を届けるため、Firebase Cloud Messagingのトークンを取得・保存します。
購入情報 サブスクリプションおよびアプリ内課金(消費型)の購入・購読状況は、Appleのシステム(StoreKit)を通じて管理され、開発者が決済情報(カード番号など)を直接取得することはありません。

情報の利用目的

  • 「友達に見てもらう」「友達と一緒に撮る」機能の提供のため
  • フレンド関係の管理、招待通知の送信のため
  • サブスクリプション・アプリ内課金の提供、購読状態の確認のため
  • 不具合の調査、お問い合わせへの対応のため

開発者は、取得した情報を広告配信や第三者へのマーケティング目的で利用することはありません。

第三者への提供・委託先

本アプリは、以下の外部サービス(Google LLCが提供するFirebase)を利用しています。 これらのサービスは、本アプリの機能提供に必要な範囲でのみ情報を取り扱います。

  • Firebase Authentication(匿名認証)
  • Firebase Firestore(データベース)
  • Firebase Storage(写真の一時保存)
  • Firebase Cloud Messaging(プッシュ通知)
  • Firebase Cloud Functions(通知送信処理)

各サービスの取り扱いについては、Googleのプライバシーポリシーもあわせてご確認ください。

データの保存期間・削除

  • 端末内に保存された写真は、ユーザー自身が削除するまで保持されます。アプリを削除すると、端末内のデータは失われます。
  • 相手に共有するために一時的にアップロードされた写真は、相手が受け取った時点で自動的に削除されます。
  • フレンド・セッション情報の削除をご希望の場合は、下記のお問い合わせ先までご連絡ください。

お子様のプライバシーについて
